# Paso 14: verificar si tenés Git instalado

Perfecto. Entonces vamos a empezar por lo más simple.

## Lo único que quiero que hagas ahora

Abrí una terminal en tu computadora y corré este comando:

```bash
git --version
```

## Qué puede pasar

### Caso 1: Git está instalado

Si Git está instalado, vas a ver algo parecido a esto:

```text
git version 2.49.0
```

No tiene que ser exactamente ese número. Lo importante es que aparezca algo como `git version ...`.

### Caso 2: Git NO está instalado

Si Git no está instalado, te va a aparecer un mensaje de error parecido a estos:

- `'git' no se reconoce como un comando interno o externo`
- o algo equivalente en inglés.

## Qué quiero que me mandes

Quiero que me pegues exactamente lo que te devuelve la terminal cuando corras:

```bash
git --version
```

## Muy importante

En este paso no tenés que hacer nada más.

Solo ejecutar ese comando y pasarme el resultado.
