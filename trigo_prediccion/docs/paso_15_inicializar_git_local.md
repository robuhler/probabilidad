# Paso 15: inicializar Git en tu proyecto local

Excelente: Git ya está instalado en tu computadora.

Tu resultado fue correcto porque apareció algo como:

- `git version 2.52.0.windows.1`

## Objetivo de este paso

Ahora vamos a hacer que tu carpeta del proyecto quede bajo control de versiones con Git.

## Lo que quiero que hagas ahora

### 1. Abrí una terminal ubicada dentro de la carpeta del proyecto

La carpeta del proyecto es la carpeta principal donde estás trabajando con PyCharm.

### 2. Corré este comando

```bash
git init
```

## Qué debería pasar

Deberías ver un mensaje parecido a alguno de estos:

- `Initialized empty Git repository in ...`
- o un mensaje equivalente indicando que el repositorio Git fue inicializado.

## Después de eso

Corré este segundo comando:

```bash
git status
```

## Qué quiero que me mandes

Quiero que me pegues la salida completa de estos dos comandos:

```bash
git init
git status
```

## Importante

En este paso todavía no vamos a hacer `git add`, ni `commit`, ni GitHub.

Solo quiero confirmar que el proyecto quedó inicializado con Git correctamente.
