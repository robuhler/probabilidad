# Paso 3: pensar las fuentes de datos

Ahora no quiero que elijamos más variables.

Ahora quiero que pensemos algo más importante: **de dónde vamos a sacar cada dato**.

## Objetivo de este paso

Para cada variable del MVP, necesitamos responder estas dos preguntas:

1. ¿De qué fuente va a salir?
2. ¿Con qué frecuencia vamos a poder actualizarla?

## Variables que tenemos que cubrir en este paso

1. precio spot del trigo,
2. precio futuro del trigo,
3. precio internacional de referencia,
4. tipo de cambio,
5. producción o condición de campaña.

## Qué quiero que me digas ahora

Quiero que me cuentes, por tu experiencia de trabajo, si hoy ustedes miran alguna fuente concreta para alguna de estas variables.

Por ejemplo:

- un mercado,
- una pizarra,
- una página oficial,
- un informe privado,
- una planilla interna del molino.

## Como profesor, qué estamos buscando en este paso

No estamos buscando todavía la fuente perfecta.

Estamos buscando una fuente que sea:

- confiable,
- entendible,
- repetible en el tiempo,
- útil para una actualización semanal.

## Tu tarea para el próximo intercambio

Decime, aunque sea de forma preliminar, de dónde creés que podríamos obtener estas 5 variables.

Si todavía no sabés alguna, no pasa nada: la pensamos juntos.
